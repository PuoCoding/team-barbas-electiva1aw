# team-barbas-electiva1aw
Un Jardín de niños requiere una aplicación web donde los docentes y padres de familia puedan mantener el control y consultar la información de los niños. De tal forma que se puedan subir notas, consultar notas, observaciones o anotaciones, visualizar cámaras de seguridad, información médica y de contacto, horarios escolares e información de pagos.
